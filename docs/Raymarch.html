Wgsl

module

Module

provides canonical WGSL snippets for the raymarching core.

default-config

defn

(Fn [] RaymarchConfig) 

                        (default-config)

returns a standard balanced traversal configuration.

estimate-normal

defn

(Fn [(Ref (Fn [(Ref (Vector3 Double) a)] b c) d), (Ref (Vector3 Double) e), Double] (Vector3 b)) 

                        (estimate-normal sdf p eps)

calculates the surface normal at point 'p' using finite differences. Scale awareness is provided by the 'eps' parameter.

march

defn

(Fn [(Ref (Fn [(Ref (Vector3 Double) a)] Double b) c), (Ref Ray d), (Ref RaymarchConfig e)] RaymarchHit) 

                        (march sdf ray config)

traverses space using the 'sdf' function until a surface is hit or 'max-dist' is reached.
