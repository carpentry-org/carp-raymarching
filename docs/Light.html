Light

represents a point light source.

color

instantiate

(Fn [(Ref Light a)] (Ref (Vector3 Double) a))

gets the color property of a Light.

copy

instantiate

(Fn [(Ref Light a)] Light)

copies a Light.

delete

instantiate

(Fn [Light] ())

deletes a Light. Should usually not be called manually.

init

instantiate

(Fn [(Vector3 Double), (Vector3 Double)] Light)

creates a Light.

pos

instantiate

(Fn [(Ref Light a)] (Ref (Vector3 Double) a))

gets the pos property of a Light.

prn

instantiate

(Fn [(Ref Light a)] String)

converts a Light to a string.

set-color

instantiate

(Fn [Light, (Vector3 Double)] Light)

sets the color property of a Light.

set-color!

instantiate

(Fn [(Ref Light a), (Vector3 Double)] ())

sets the color property of a Light in place.

set-pos

instantiate

(Fn [Light, (Vector3 Double)] Light)

sets the pos property of a Light.

set-pos!

instantiate

(Fn [(Ref Light a), (Vector3 Double)] ())

sets the pos property of a Light in place.

str

instantiate

(Fn [(Ref Light a)] String)

converts a Light to a string.

instantiate

(Fn [Light, (Ref (Fn [(Vector3 Double)] (Vector3 Double) a) b)] Light)

instantiate

(Fn [Light, (Ref (Fn [(Vector3 Double)] (Vector3 Double) a) b)] Light)
