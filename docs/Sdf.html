Sdf

is a module for Signed Distance Field (SDF) mathematics.

Sign Convention

  • Negative values: Inside the surface.
  • Positive values: Outside the surface.
  • Zero: On the surface boundary.

Wgsl

module

Module

box

defn

(Fn [(Ref (Vector3 Double) a), (Ref (Vector3 Double) b)] Double) 

                        (box p b)

returns the signed distance to a 3D box at the origin with half-dimensions 'b'.

capsule

defn

(Fn [(Ref (Vector3 Double) a), (Ref (Vector3 Double) b), (Ref (Vector3 Double) c), Double] Double) 

                        (capsule p a b r)

returns the signed distance to a capsule between points 'a' and 'b' with radius 'r'. Correctly handles degenerate segments (a == b) by treating them as spheres.

cylinder

defn

(Fn [(Ref (Vector3 Double) a), Double, Double] Double) 

                        (cylinder p r h)

returns the signed distance to a vertical cylinder with radius 'r' and height 'h'.

intersect

defn

(Fn [a, a] a) 

                        (intersect a b)

returns the intersection of two distance fields (A ∩ B).

onion

defn

(Fn [a, a] a) 

                        (onion d thickness)

hollows out an SDF shape to a specific thickness.

plane

defn

(Fn [(Ref (Vector3 a) b), (Ref (Vector3 a) c), a] a) 

                        (plane p n h)

returns the signed distance to a plane with normal 'n' (must be normalized) and distance from origin 'h'.

repeat

defn

(Fn [(Ref (Vector3 Double) a), (Ref (Vector3 Double) b)] (Vector3 Double)) 

                        (repeat p c)

repeats space infinitely with a period 'c'. A component of 0.0 in 'c' skips repetition on that axis.

round

defn

(Fn [a, a] a) 

                        (round d r)

scale-space

defn

(Fn [(Ref (Vector3 Double) a), Double] (Vector3 Double)) 

                        (scale-space p s)

scales the query space by factor 's'.

Note: This only transforms the coordinate space. To preserve correct distances, you must multiply the final SDF result by 's'. Example: (* s (Sdf.sphere (Sdf.scale-space p s) r))

smooth-intersect

defn

(Fn [Double, Double, Double] Double) 

                        (smooth-intersect a b k)

returns a smooth intersection (A ∩ B). Handles k=0 by falling back to standard intersect.

smooth-subtract

defn

(Fn [Double, Double, Double] Double) 

                        (smooth-subtract a b k)

returns a smooth subtraction (A - B). Handles k=0 by falling back to standard subtract.

smooth-union

defn

(Fn [Double, Double, Double] Double) 

                        (smooth-union a b k)

returns a smooth union of two distance fields (IQ formulation). Handles k=0 by falling back to standard union.

torus

defn

(Fn [(Ref (Vector3 a) b), (Ref (Vector2 a) c)] a) 

                        (torus p t)

returns the signed distance to a torus with major radius 'tx' and minor radius 'ty'.

translate

defn

(Fn [(Ref (Vector3 a) b), (Ref (Vector3 a) c)] (Vector3 a)) 

                        (translate p t)
